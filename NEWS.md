# oissyntheticdata 3.0.0

* First version of the R package. It ships `gov_one.R` 3.0.0, the R twin of
  `gov_one.py` 3.0.0 (the 'Python' package `oissyntheticdata` 3.0.0), unchanged.
* `gov_one()` loads the tool; `gov_one_profile()`, `gov_one_synth()`,
  `gov_one_check()` and `gov_one_settings()` run its commands on a folder;
  `gov_one_export()` copies `gov_one.R` and `analysis_template.R` out, to be
  carried into a place where no package can be installed.
